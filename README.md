# Programação Para Dispositivos Móveis

> [!NOTE]
> O presente repositório busca suprir a demanda da matéria Programação Para internet do curso de informática do IFSC. Nele foram feitas aplicações no Android Studio, sendo cada branch uma função diferente. 

## 💻 Pré-requisitos

Antes de começar, verifique se você atendeu aos seguintes requisitos:

- Você tem uma máquina com Android Studio instalado. 

## 🚀 Instalação

Para instalar o projeto, siga estas etapas:

No terminal do Git Bash rode: 
```
git clone https://github.com/oliver-santos1108/ProgramacaoParaDispositivosMoveis.git
```
Escolha a branch que deseja:
```
git switch NomeBranch
```
